Grid Setup: 50x50x20 grid, CO2 in kg/m3, buildings as -1. 
Emission Modeling: Add sources (traffic, industry, household) from sources table, scaled by intensity, limited by active_hours. 
Dispersion (Time-Based): 3D Gaussian filter over time steps (e.g., hourly), adjusted by wind (OpenWeatherMap API), blocked by buildings. 
Interventions (Unique Mechanics): Reduce CO2 with type-specific methods - linear for biofilters (sorption/biodegradation along path), spherical for roadside units, surface for vertical gardens; respect capacity, optimize with SciPy minimize. 
Sensor Integration: Calibrate grid with sensor CO2 ppm per time step, use wind data from API. 
Workflow: Initialize grid, for each time step: add emissions, disperse, apply interventions (type-specific), optimize, predict, calibrate, store in simulations table. 
Predictions: Calculate CO2 reduction (%), avg ppm (510*kg/m^3), AQI (Good: <400, Moderate: 400-1000, Poor: >1000), per time step or averaged.
